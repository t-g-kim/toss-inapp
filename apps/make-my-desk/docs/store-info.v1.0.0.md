### 📋 상세 설명 (그대로 복사하여 콘솔에 입력)
```text
내 방과 사무실을 감성 넘치는 작업실로! 실패 없는 데스크테리어 맞춤 견적 서비스입니다.

[주요 기능 안내]
1. 예산별 인기 데스크 프리셋 (1초 원클릭 적용)
- 30만원 알뜰 자취/학생 셋업부터 60만원 화이트 미니멀, 100만원 개발자 맥북 듀얼, 150만원 게이밍, 220만원 하이엔드 모션데스크까지 최적의 조합을 즉시 불러옵니다.

2. 스마트 호환성 진단 엔진
- 모니터 무게(kg)와 모니터암 최대 지지 하중을 실시간 대조하여 처짐 위험을 사전 감지합니다.
- 책상 상판 두께와 클램프 체결 호환성을 1초 만에 확인합니다.

3. 인터랙티브 데스크 2D 시각화
- 선택한 책상 색상(우드/화이트/블랙), 모니터 크기, 모니터암, 스크린바 조명, 의자를 실시간 시뮬레이션으로 한눈에 확인합니다.
- '밤 감성 모드'를 통해 모니터 라이트바와 앰비언트 LED 조명 효과를 미리 체험해 보세요.

4. 7종 부품 커스텀 & 최저가 구매 연동
- 책상, 모니터, 모니터암, 의자, 키보드/마우스, 조명/데스크매트, 케이블 정리함까지 내 취향대로 부품을 바꾸고, 쿠팡 로켓배송과 다나와 최저가 링크로 바로 연결됩니다.

5. 견적서 원클릭 복사 & 보관함
- 완성된 견적서를 클립보드로 한 번에 복사하여 친구나 커뮤니티에 공유하거나 보관함에 저장할 수 있습니다.
```
