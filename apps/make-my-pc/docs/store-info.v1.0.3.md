# 토스 콘솔 등록 정보 - v1.0.3 (실시간 원격 시세 자동 동기화 및 카탈로그 최신화)

- **버전**: v1.0.3 (새 버전 번들 배포용)
- **번들 파일**: `apps/make-my-pc/make-my-pc.ait`
- **배포일**: 2026-11-02

## 📌 버전 업데이트 주요 내역 (v1.0.3)

1. **원격 최신 부품 시세 실시간 자동 동기화(`syncRemoteCatalog`) 탑재**:
   - 앱 진입 시 및 상단 `[시세]` 동기화 버튼 클릭 시, 매일 3회(8시간 주기) 자동 수집되는 최신 다나와·쿠팡 부품 카탈로그(`catalog-latest.json`)를 실시간으로 불러와 즉시 반영하도록 개선했습니다.
   - 이제 번들 재배포 없이도 항상 당일 최신 부품 시세와 최저가 구매 링크가 자동 유지됩니다.
2. **109종 전 부품 최신 시세 반영 및 로컬 캐싱 고도화**:
   - CPU, 그래픽카드, 메인보드, RAM, SSD, 쿨러, 파워, 케이스 총 109종 부품의 최신 실거래가와 구매 링크를 업데이트하고, 오프라인/네트워크 지연 환경에서도 최신 시세를 즉시 불러오도록 스토리지 캐싱을 적용했습니다.
3. **3D 뷰어 및 결제 모달 안정성 개선**:
   - Three.js 3D 부품 뷰어 메모리 해제 및 토스페이 결제 모달 상품명 표기 호환성을 강화했습니다.

## 5. 버전 변경 이력 (Changelog)

- **v1.0.3 (2026-11-02)**:
  - **실시간 원격 시세 자동 동기화 탑재**: 앱 진입 및 시세 동기화 버튼 클릭 시 GitHub Actions 배치가 수집한 최신 `catalog-latest.json`을 실시간 fetch하여 번들 재업로드 없이도 최신 날짜·가격이 즉시 반영되도록 개선.
  - **109종 전 부품 최신 실거래가 업데이트**: 최신 다나와 최저가 및 쿠팡 파트너스 연동 시세 반영.
  - **3D 뷰어 및 모달 안정성 개선**: Three.js 렌더링 정리 및 결제 모달 호환성 보강.
- **v1.0.2 (2026-10-12)**:
  - **부품 시세 전수 정규화**: 되팔이/구매대행 비정상 왜곡 시세 55개 품목을 2026 표준 실거래가로 전수 교정.
  - **이상치 방어 필터 적용**: 기준 정가 대비 0.6배~1.45배 범위를 벗어나는 수집가는 자동 필터링(Plausibility Validation).
  - **부품 선택 UI 개선**: 모바일 화면에서 부품 선택 시 줄바꿈(개행) 방지 및 원형 체크 인디케이터(라디오 불릿) 신설.
- **v1.0.1 (2026-10-12)**:
  - 앱 로고 규격 개편 (투명 배경 제거, 순백색 #FFFFFF 불투명 600x600).
  - 내비게이션 바 중복 방지를 위한 웹뷰 자체 헤더 정리.
- **v1.0.0 (2026-10-12)**:
  - 최초 출시 번들.
