## 6. 버전 변경 이력 (Changelog)

### `v1.0.0` (2026-11-11)
- 인터랙티브 세계지도 줌/패닝 뷰어(`WorldMapViewer`) 및 유럽·미주·아시아 대륙별 카메라 프리셋 탑재
- 세계 10대 미술관 및 퍼블릭 도메인 16대 불멸의 명화 카탈로그 구축
- 초고화질 돋보기(1.0x ~ 3.5x) 및 그림 속 숨은 비밀 포인트(①②③) 인터랙티브 터치 도슨트 구현
- Web Speech API + Web Audio API 클래식 화음 기반 1분 오디오 도슨트 탑재
- 세계 미술관 아트 여권 스탬프 북 및 HTML5 Canvas 기반 나만의 미술관 티켓 포토카드 PNG 발급 기능 구현
